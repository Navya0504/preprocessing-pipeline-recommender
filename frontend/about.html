How PreprocessAI works

Multi-objective meta-learning for explainable preprocessing pipeline recommendation.

01 · Dataset profiling

Extract dataset characteristics including size, missingness, numeric/categorical types, skewness, outlier fraction and correlations.

02 · Candidate pipelines

Consider compatible imputation, encoding, scaling, outlier handling and class-imbalance strategies.

03 · Multi-objective evaluation

Compare candidates across performance, efficiency, simplicity, robustness and explainability using backend evaluations.

04 · Explain and report

Select a Pareto-optimal recommendation, explain trade-offs and produce a printable A4 report.

Research prototype and data privacy

The frontend follows the team's integration contract. Actual ML predictions, cross-validation scores and explanations come from the FastAPI backend. The local login is a demonstration only, not a production authentication system. Avoid uploading sensitive personal datasets until the backend and hosting environment have been secured.
